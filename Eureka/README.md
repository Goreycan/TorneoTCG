# Eureka Server

Este módulo es un servidor Eureka para el registro de servicios en el ecosistema Spring Cloud.

## Requisitos

- Java 21
- Maven

## Ejecución

Desde la raíz del módulo:

```bash
mvn spring-boot:run
```

El servidor Eureka estará disponible en:

```text
http://localhost:8761
```

## Pruebas

Ejecuta las pruebas con:

```bash
mvn test
```
